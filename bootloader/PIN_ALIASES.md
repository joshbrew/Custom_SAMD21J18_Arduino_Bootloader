# Generated Custom Arduino pin aliases

Applies to `custom:samd:custom_j18`, not the Zero profile. Numbers are Arduino table indices.

| Alias | Physical pin | Arduino index |
|---|---|---|
| `PIN_LED` | PA05 | 5 |
| `PIN_UART0_TX` | PA22 | 32 |
| `PIN_UART0_RX` | PA23 | 33 |
| `PIN_UART1_TX` | PA16 | 26 |
| `PIN_UART1_RX` | PA17 | 27 |
| `PIN_SDA` | PA08 | 16 |
| `PIN_SCL` | PA09 | 17 |
| `PIN_SPI0_MOSI` | PB12 | 42 |
| `PIN_SPI0_SCK` | PB13 | 43 |
| `PIN_SPI0_MISO` | PB11 | 41 |
| `PIN_CS0` | PB10 | 40 |
| `PIN_SPI1_MOSI` | PB16 | 46 |
| `PIN_SPI1_SCK` | PB17 | 47 |
| `PIN_SPI1_MISO` | PB22 | 48 |
| `PIN_CS1` | PB14 | 44 |

All package GPIOs also have `J18_PIN_PAxx` / `J18_PIN_PBxx` aliases. USB, SWD, and crystal pins are reserved.
